# Agent guide

- Prefer `pnpm test` and `pnpm typecheck` after substantive changes.
- Do not modify `packages/kernel` unless policy explicitly allows it.
- Read `docs/SELF.md` before self-maintenance work.
- Keep the event log append-only. Fork conversations or clone agents instead of
  rewriting history.
- Stage only the files you intend to commit. Never force-push.
